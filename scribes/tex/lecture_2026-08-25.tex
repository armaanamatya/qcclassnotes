\section{Efficient Algorithms: Primes and Factoring}

To decide whether a number $n$ is prime, the input is the binary representation of $n$, so the
\emph{input size} is $N = \log_2 n$ bits. An algorithm is \textbf{efficient} if it runs in time
polynomial in the input size, here $\bigO{(\log_2 n)^k}$ for a constant $k$.

Trial division up to $\sqrt{n}$ takes $\bigTh{\sqrt{n}} = \bigTh{2^{N/2}}$ time, which is exponential.
A deterministic polynomial-time algorithm exists ($\tilde{\mathcal{O}}(N^{6})$) but is not used in
practice. The \emph{randomized} Miller--Rabin test takes $\bigO{N^3}$ time: if $n$ is composite, at
least $\sfrac{3}{4}$ of the numbers in $\set{2, \dots, n-2}$ are \emph{witnesses} of this, and a prime
has no witness, so after $k$ independent samples a composite $n$ goes undetected with probability at
most $\left(\sfrac{1}{4}\right)^k$.

\paragraph{Factoring.} Given $n = pq$ with $p, q$ prime, find $p$ and $q$. Factoring is an
\emph{encryption primitive}: if it can be solved quickly, the encryption is broken. No polynomial-time
classical algorithm is known, but \emph{Shor's factoring algorithm} is a quantum algorithm with
polynomial running time $\bigO{N^3}$. There is \emph{no} known quantum algorithm that solves
\nptime-complete problems (the hardest problems whose solutions can be verified in polynomial time,
such as 3-SAT) in polynomial time.

\section{Random Sampling}

A randomized algorithm only needs to \emph{sample}. We assume that flipping a (fair) coin is an
$\bigO{1}$ time primitive. Consider an array with $n$ slots (\cref{fig:coinflips-0825}), $n$ a power
of $2$. Every index has $\log n$ bits, so flipping one coin for each bit samples a uniformly random
element in $\bigO{\log n}$ time:
$\prob{\text{index $i$ is chosen}} = \left(\sfrac{1}{2}\right)^{\log n} = \sfrac{1}{n}$ for every $i$.

Sampling can be done \emph{with} or \emph{without} replacement. We analyze sampling with replacement,
since otherwise the samples are not independent. A sample hits a given element with probability
$\sfrac{1}{n}$, so finding it takes $\expectation{\text{samples}} = \frac{1}{\sfrac{1}{n}} = n$
samples in expectation.

\section{Search}

An unsorted array $A$ with $n$ slots can only be accessed through \emph{queries} (``what is
$A[i]$?''), and we want the index of a given element $x$. Linear search makes $\bigO{n}$ queries.
For a lower bound, which has to hold for \emph{all} algorithms, we use an \emph{adversary argument}:
the adversary constructs an input on which the given algorithm performs badly.

\begin{theorem}[Lower Bound for Deterministic Search]\label{thm:detsearch-0825}
    Every deterministic algorithm for search makes at least $n - 1$ queries in the worst case.
\end{theorem}

\begin{proof}
    Whenever the algorithm queries a slot $i$, the adversary answers that $A[i] \neq x$. The algorithm
    is deterministic, so this defines one run. Suppose that it stops after $k \leq n - 2$ queries and
    outputs an index $j$. At least $2$ slots have not been queried, so the adversary can place $x$ in
    an unqueried slot different from $j$. This array is consistent with all the answers, and the
    algorithm is wrong on it. So a correct algorithm makes at least $n - 1$ queries.
\end{proof}

The argument does not apply to \emph{randomized} algorithms, whose queries are not determined by the
previous answers. Randomized search still needs $\bigOm{n}$ expected queries, by \emph{Yao's min-max
principle}, and Grover's quantum algorithm needs $\bigO{\sqrt{n}}$ queries. To show a \emph{quantum
advantage} for a problem, we have to show that it needs $\bigOm{f(n)}$ queries classically but only
$\littleO{f(n)}$ queries quantumly.

\section{Probability}

A \textbf{sample space} $S$ is a finite set of \emph{simple events}, $\abs{S} = n$. A
\textbf{probability function} $\Pr \colon S \to [0,1]$ assigns a probability to every simple event.
An \textbf{event} is a subset $A \subseteq S$, with $\prob{A} = \sum_{a \in A} \prob{a}$. The
\emph{axioms} are $\prob{A} \geq 0$, $\prob{S} = 1$, and
$\prob{A_1 \cup \dots \cup A_n} = \sum_{i=1}^{n} \prob{A_i}$ for pairwise disjoint events
($A_i \cap A_j = \emptyset$ for all $i \neq j$). A \textbf{random variable} is a function
$X \colon S \to V$ to a set of values $V$, with $\prob{X = r} = \sum_{s \in S \,:\, X(s) = r} \prob{s}$.

In this lecture, we turn to distributed computing. We define the synchronous complete network model,
study the leader election problem, and analyze a randomized algorithm that elects a leader in $\bigO{1}$
rounds with only $\bigO{\sqrt{n} \log^{\sfrac{3}{2}} n}$ messages. We then take a first look at random
walks on undirected graphs, and we prove the weak law of large numbers with Chebyshev's inequality.

\section{Distributed Computing in a Complete Network}

The network is a \emph{complete graph} $G$ on $n$ nodes (\cref{fig:network-0908}): every pair of nodes
is joined by a bidirectional edge, so there are $\binom{n}{2} = \frac{n(n-1)}{2}$ edges in total and
every node has $n - 1$ incident edges. The nodes are computers, and an edge is a communication link
on which a message can be sent in either direction.

The network is \emph{synchronous}: all nodes share a clock, and the computation proceeds in
\emph{rounds} (also called steps). In one round, every node
\[\text{receives} \longrightarrow \text{computes} \longrightarrow \text{sends},\]
i.e., it receives the messages that were sent to it in the previous round, does an arbitrary local
computation, and sends messages on some of its edges.

\subsection{Leader Election}

\begin{problem}[Leader Election]
    All nodes run the same algorithm. At the end, exactly one node must be
    in the state \emph{leader}, and all other nodes must be in the state \emph{non-leader}.
\end{problem}

There are two goals.
\begin{itemize}
    \item Finish fast: minimize the number of rounds.
    \item Less communication: minimize the total number of messages sent.
\end{itemize}
The nodes are either \emph{labelled}, i.e., every node has a unique id, or \emph{anonymous}, i.e., the
nodes have no ids and cannot be told apart.

\paragraph{The trivial algorithm.} With unique ids, every node sends its id to all other nodes in the
first round, and the node with the minimum id becomes the leader. Every node learns all $n$ ids, so
exactly one node sees that its own id is the minimum. Messages are sent in $1$ round only (the ids
are received and compared at the start of round $2$), so this takes $\bigO{1}$ rounds, and each of
the $n$ nodes sends $n - 1$ messages, so the total number of messages is $n(n-1) = \bigTh{n^2}$: two on every edge.

\paragraph{Anonymous nodes.} For anonymous nodes there is no deterministic algorithm. To state this
precisely we have to say how a node addresses its edges: it has $n - 1$ \emph{ports}, numbered
$1, \dots, n-1$, one per incident edge, and it can send a message on a given port and sees on which
port a message arrives. The node does not know which node is at the other end of a port, and the
port numbering is not under the control of the algorithm (we may think of it as chosen by an
adversary).

\begin{theorem}[No Deterministic Leader Election for Anonymous Nodes]\label{thm:anonymous-0908}
    Let $n \geq 2$. In an anonymous complete network in which all nodes start in the same state, there
    is no deterministic algorithm that elects a leader for every port numbering.
\end{theorem}

\begin{proof}
    Fix a deterministic algorithm. We choose the following symmetric port numbering. Identify the
    nodes with $\mathbb{Z}_n = \set{0, 1, \dots, n-1}$, with addition modulo $n$, and let port $j$ of
    node $i$ lead to node $i + j$, for $j = 1, \dots, n-1$. This is a valid port numbering: the nodes
    $i + 1, \dots, i + (n-1)$ are exactly the $n - 1$ nodes other than $i$. The edge between $i$ and
    $i + j$ is port $j$ at $i$ and port $n - j$ at $i + j$, since $(i + j) + (n - j) = i$ in
    $\mathbb{Z}_n$. Hence a message that some node sends on port $j$ arrives at its destination on
    port $n - j$.

    We show by induction on $t$ that at the end of round $t$ all nodes are in the same state, and
    that in round $t$ all nodes send the same message on port $j$, for every $j$ (where ``no message''
    counts as a message). For $t = 0$ all nodes are in the same initial state, and nothing has been
    sent. Assume that the claim holds for round $t - 1$, and let $m_j$ be the message that every node
    sent on port $j$ in round $t - 1$. In round $t$, node $i$ receives on port $q$ the message that
    node $i + q$ sent on its port $n - q$, which is $m_{n-q}$. This does not depend on $i$, so all
    nodes receive the same messages on the same ports. They were in the same state, and the algorithm
    is deterministic, so they compute the same new state and send the same messages on the same
    ports. This proves the claim.

    Whether a node declares itself the leader is a function of its state. Therefore, at every time,
    either all $n \geq 2$ nodes are leaders or no node is a leader, and there is never exactly one
    leader.
\end{proof}

A randomized algorithm can break this symmetry: if every node picks an id uniformly at random in
$\set{1, \dots, n^4}$, then two given nodes pick the same id with probability $\sfrac{1}{n^4}$, so by
the union bound over the $\binom{n}{2} \leq \sfrac{n^2}{2}$ pairs all ids are different with probability
at least $1 - \frac{1}{2n^2}$. From now on we assume that the nodes are non-anonymous and have unique
ids.

\paragraph{Complexity classes.} The same three kinds of algorithms (deterministic, randomized,
quantum) appear in the complexity classes
\[\mathrm{P} \subseteq \mathrm{BPP} \subseteq \mathrm{BQP},\]
where $\mathrm{P}$ is deterministic polynomial time, $\mathrm{BPP}$ is bounded-error probabilistic
polynomial time, and $\mathrm{BQP}$ is bounded-error quantum polynomial time. The first inclusion
holds because a deterministic algorithm is a randomized algorithm that ignores its coins; the second
is recorded without proof.

\section{A Randomized Algorithm for Leader Election}

Throughout, $\log$ is the natural logarithm, and
\[p = \frac{2 \log n}{n}, \qquad k = \left\lceil \sqrt{n \log n} \right\rceil.\]
We have $p \leq 1$ and $k \leq n$ for every $n \geq 1$, since $2 \log n \leq n$. The algorithm has
four steps.
\begin{enumerate}
    \item \textbf{Subsample candidates.} Every node becomes a \emph{candidate} with probability $p$,
          independently of all other nodes.
    \item \textbf{Candidates contact referees.} Every candidate sends its id to $k$ random nodes,
          its \emph{referees}.
    \item \textbf{Referee round.} Every node that received at least one id declares the minimum id
          among the received messages the \emph{winner}, and replies with the winner's id to all
          candidates that contacted it.
    \item \textbf{Decision.} A candidate becomes the leader if it is the winner at all of its
          referees. All other nodes are non-leaders.
\end{enumerate}

\paragraph{The model for the random choices.} We fix the following precise model, which the analysis
below uses. Every node $u$ draws a coin $C_u \in \set{0,1}$ with $\prob{C_u = 1} = p$ ($u$ is a
candidate if $C_u = 1$) and a \emph{referee set} $R_u$, which is a uniformly random set of $k$
distinct nodes among all $n$ nodes. All the $C_u$ and all the $R_u$ are mutually independent. Only
candidates use their referee sets. A candidate may pick itself as a referee; then it plays the role
of this referee itself, and no message is needed.

\subsection{The Number of Candidates}

Let $X = \sum_{u} C_u$ be the number of candidates. By linearity of expectation,
\[\expectation{X} = \frac{2 \log n}{n} \cdot n = 2 \log n.\]

% Notes p.6: "Atleast 1 leader <- Show".
\begin{exercise}\label{ex:atleast-0908}
    Show that, with high probability, there is at least $1$ leader.
\end{exercise}

The solution is \cref{thm:leader-atleast-0908}.

\begin{theorem}[At Least One Leader]\label{thm:leader-atleast-0908}
    There is at least one leader if and only if there is at least one candidate, and
    \[\prob{\text{no leader}} = \prob{X = 0} \leq \frac{1}{n^2},
        \qquad\text{i.e.,}\qquad
        \prob{\text{at least $1$ leader}} \geq 1 - \frac{1}{n^2}.\]
\end{theorem}

\begin{proof}
    Only candidates become leaders, so if $X = 0$ there is no leader. Conversely, assume $X \geq 1$,
    and let $w$ be the candidate with the minimum id among all candidates (it is unique, since the
    ids are unique). Let $r$ be any referee of $w$. The ids that $r$ receives are ids of candidates,
    so all of them are at least the id of $w$, and the id of $w$ is one of them. Hence $r$ declares
    $w$ the winner. This holds for every referee of $w$, so $w$ is a leader.

    It remains to bound $\prob{X = 0}$. The coins are independent, so, using $1 - x \leq e^{-x}$,
    \[\prob{X = 0} = \left(1 - \frac{2 \log n}{n}\right)^{n}
        \leq e^{-\frac{2 \log n}{n} \cdot n} = e^{-2 \log n} = \frac{1}{n^2}.\]
    Here we used $0 \leq 1 - \frac{2 \log n}{n}$, so that taking the $\nth{n}$ power preserves the
    inequality.
\end{proof}

\paragraph{Remark (the Chernoff computation).} In class, $\prob{X < 1}$ was bounded ``from Chernoff
bounds'', with $(1 - \delta) \cdot 2 \log n = 1$, i.e., $\delta = 1 - \frac{1}{2 \log n}$. The lower tail
of \cref{thm:chernoff-0901} is an inequality with a factor $\sfrac{1}{2}$ in the exponent, and with
$\mu = 2 \log n$ it gives
\[\prob{X < 1} \leq e^{-\frac{\mu \delta^2}{2}}
    = e^{-\log n \left(1 - \frac{1}{2 \log n}\right)^2}
    = \frac{e}{n} \cdot e^{-\frac{1}{4 \log n}}
    \leq \frac{e}{n}\]
for $n \geq 2$. So the lower tail bound in this form only gives $\bigO{\sfrac{1}{n}}$ here; the value $\sfrac{1}{n^2}$
recorded in class is the one that the direct computation above gives.

\subsection{At Most One Leader}

% Notes p.6: "Almost 1 leader <- Show" (i.e., at most 1 leader), followed by the computation
% (1 - sqrt(n log n)/n)^{sqrt(n log n)} <= ... = 1/n on pp.6-7.
\begin{exercise}\label{ex:atmost-0908}
    Show that, with probability tending to $1$, there is at most $1$ leader.
\end{exercise}

We prove this in \cref{thm:leader-atmost-0908}, using \cref{lem:badpair-0908,lem:disjoint-0908}.
In the notes this is written ``almost $1$ leader''; we read it as ``at most $1$ leader''. Read
literally, as ``almost surely exactly $1$ leader'', it is \cref{thm:leader-0908} below.

Call a pair of different nodes $\set{u,v}$ a \emph{bad pair} if both are candidates and they have
no common referee, i.e., $C_u = C_v = 1$ and $R_u \cap R_v = \emptyset$.

\begin{lemma}[Two Leaders Form a Bad Pair]\label{lem:badpair-0908}
    If two candidates have a common referee, then at most one of them is a leader. Consequently, if
    there is more than one leader, then there is a bad pair.
\end{lemma}

\begin{proof}
    Let $u \neq v$ be candidates with a common referee $r$, and assume that the id of $u$ is smaller
    than the id of $v$ (\cref{fig:network-0908}). The referee $r$ receives both ids (if $r$ is $u$ or $v$ itself, it knows its own id), so the minimum
    id that it receives is at most the id of $u$, which is smaller than the id of $v$. Hence $r$ does
    not declare $v$ the winner, and $v$ is not a leader. Consequently, two different leaders are two
    candidates without a common referee, i.e., a bad pair.
\end{proof}

\begin{lemma}[Two Referee Sets Rarely Miss Each Other]\label{lem:disjoint-0908}
    For any two different nodes $u$ and $v$,
    \[\prob{R_u \cap R_v = \emptyset} \leq \left(1 - \frac{k}{n}\right)^{k}
        \leq e^{-\sfrac{k^2}{n}} \leq \frac{1}{n}.\]
\end{lemma}

\begin{proof}
    Condition on $R_u = S$, where $S$ is any set of $k$ nodes. Since $R_v$ is independent of $R_u$,
    it is still a uniformly random set of $k$ nodes. If $2k > n$, two sets of $k$ nodes cannot be
    disjoint, the probability is $0$, and there is nothing to show. So let $2k \leq n$. We draw the
    $k$ nodes of $R_v$ one after the other, each uniformly among the nodes not drawn yet. Assume
    that the first $i$ nodes drawn are outside $S$. Then $n - i$ nodes are left, and $k$ of them
    are in $S$, so the next node is outside $S$ with probability $\frac{n - k - i}{n - i}$. Hence
    \[\prob{R_v \cap S = \emptyset}
        = \prod_{i=0}^{k-1} \frac{n - k - i}{n - i}
        = \prod_{i=0}^{k-1} \left(1 - \frac{k}{n - i}\right)
        \leq \left(1 - \frac{k}{n}\right)^{k},\]
    because every factor satisfies $0 \leq 1 - \frac{k}{n-i} \leq 1 - \frac{k}{n}$ (the first
    inequality holds since $i \leq k - 1$ and $2k \leq n$ give $n - i \geq k$). This bound does not
    depend on $S$, so it also holds without conditioning. Finally, $1 - x \leq e^{-x}$ and
    $k^2 \geq n \log n$ give
    \[\left(1 - \frac{k}{n}\right)^{k} \leq e^{-\frac{k}{n} \cdot k} = e^{-\sfrac{k^2}{n}}
        \leq e^{-\frac{n \log n}{n}} = e^{-\log n} = \frac{1}{n}.\qedhere\]
\end{proof}

With $k = \sqrt{n \log n}$, the last display is the computation from class. In the notes its left-hand
side is labelled as the probability of at most one leader; the quantity that it bounds is the
probability that one given pair of candidates has no common referee. The number of pairs of candidates
is random, so we finish with an expectation over all pairs of nodes.

\begin{theorem}[At Most One Leader]\label{thm:leader-atmost-0908}
    \[\prob{\text{more than $1$ leader}} \leq \frac{2 \log^2 n}{n}.\]
\end{theorem}

\begin{proof}
    Let $B$ be the number of bad pairs. For a fixed pair $\set{u,v}$, the coins $C_u$, $C_v$ and the
    pair of sets $(R_u, R_v)$ are independent, so by \cref{lem:disjoint-0908}
    \[\prob{\set{u,v} \text{ is a bad pair}}
        = \prob{C_u = 1} \cdot \prob{C_v = 1} \cdot \prob{R_u \cap R_v = \emptyset}
        \leq p^2 \cdot \frac{1}{n}.\]
    By linearity of expectation over the $\binom{n}{2}$ pairs of nodes,
    \[\expectation{B} \leq \binom{n}{2} \frac{p^2}{n}
        = \frac{n(n-1)}{2} \cdot \frac{4 \log^2 n}{n^2} \cdot \frac{1}{n}
        = \frac{2 (n-1) \log^2 n}{n^2}
        \leq \frac{2 \log^2 n}{n}.\]
    If there is more than one leader, then $B \geq 1$ by \cref{lem:badpair-0908}. Since $B \geq 0$,
    Markov's inequality (\cref{thm:markov}) with $b = 1$ gives
    \[\prob{\text{more than $1$ leader}} \leq \prob{B \geq 1} \leq \expectation{B}
        \leq \frac{2 \log^2 n}{n}.\qedhere\]
\end{proof}

\begin{theorem}[Exactly One Leader]\label{thm:leader-0908}
    The algorithm elects exactly one leader with probability at least
    \[1 - \frac{1}{n^2} - \frac{2 \log^2 n}{n}.\]
\end{theorem}

\begin{proof}
    The algorithm fails if there is no leader or more than one leader. By the union bound and
    \cref{thm:leader-atleast-0908,thm:leader-atmost-0908}, this has probability at most
    $\frac{1}{n^2} + \frac{2 \log^2 n}{n}$.
\end{proof}

\paragraph{Remark (the failure probability).} The bound $\frac{2 \log^2 n}{n}$ tends to $0$, but it is
not of the form $\sfrac{1}{n^c}$ with $c > 1$. This is easy to repair: let every candidate contact
$k' = \left\lceil 2\sqrt{n \log n} \right\rceil$ referees instead of $k$ (for $n \geq 9$ we have
$4 \log n \leq n$ and hence $k' \leq n$). The proof of \cref{lem:disjoint-0908} goes through with
$k'$ in place of $k$ and gives $e^{-\sfrac{k'^2}{n}} \leq e^{-4 \log n} = \sfrac{1}{n^4}$, so that
$\expectation{B} \leq \binom{n}{2} \frac{p^2}{n^4} \leq \frac{2 \log^2 n}{n^4}$. With $k'$ referees the
algorithm therefore fails with probability at most $\frac{1}{n^2} + \frac{2 \log^2 n}{n^4} \leq \frac{2}{n^2}$
(using $2 \log^2 n \leq n^2$), and the number of messages only doubles.

\subsection{Messages and Rounds}

\begin{theorem}[Complexity of the Algorithm]\label{thm:complexity-0908}
    The algorithm takes $3$ rounds, and messages are sent only in the first two. The expected number
    of messages is at most $4 k \log n = \bigO{\sqrt{n} \log^{\sfrac{3}{2}} n}$. Moreover, with
    probability at least $1 - \sfrac{1}{n^8}$, the number of messages is at most
    $24 k \log n = \bigO{\sqrt{n} \log^{\sfrac{3}{2}} n}$.
\end{theorem}

\begin{proof}
    \emph{Rounds.} In round $1$ every node draws its coin and its referee set, and, if it is a
    candidate, sends its id to its referees. In round $2$ the referees receive the ids, compute the
    minimum, and send the replies. In round $3$ the candidates receive the replies and decide; no
    message is sent.

    \emph{Messages.} Every candidate sends at most $k$ messages and gets at most $k$ replies, so the
    number of messages is at most $2kX$. Its expectation is at most
    $2k \expectation{X} = 4 k \log n$, and since $k \leq \sqrt{n \log n} + 1$, this is
    $\bigO{\sqrt{n} \log^{\sfrac{3}{2}} n}$.

    For the second statement, $X$ is a sum of independent indicator random variables with mean
    $\mu = 2 \log n$, so \cref{thm:chernoff-0901} with $R = 12 \log n = 6\mu$ gives
    \[\prob{X \geq 12 \log n} \leq 2^{-12 \log n} = e^{-12 \log 2 \cdot \log n}
        = n^{-12 \log 2} \leq \frac{1}{n^8},\]
    since $12 \log 2 \geq 8.3$. If $X < 12 \log n$, the number of messages is at most
    $2kX \leq 24 k \log n$.
\end{proof}

\section{Markov Chains: Random Walks in Undirected Graphs}

\begin{definition}[Random Walk]
    Let $G$ be an undirected graph in which every node has at least one neighbour. A \textbf{random
    walk} on $G$ is the following process: a walker starts at some node, and in every step it moves
    from its current node $u$ to a neighbouring node chosen with uniform probability, i.e., to each
    neighbour of $u$ with probability $\frac{1}{\deg(u)}$, independently of the earlier steps.
\end{definition}

We describe the walk by the row vector $p_t = (p_t^1, \dots, p_t^n)$, where $p_t^i$ is the probability
that the walker is at node $i$ after $t$ steps (this $p_t$ is not related to the candidate
probability $p$ of the last section). Since the walker is at exactly one node, the entries
of $p_t$ sum to $1$. If the walker is at node $j$ after $t$ steps, it moves to a given neighbour $i$
of $j$ with probability $\frac{1}{\deg(j)}$, so by the law of total probability
\begin{equation}\label{eq:walkstep-0908}
    p_{t+1}^i = \sum_{j \,:\, j \text{ is a neighbour of } i} \frac{p_t^j}{\deg(j)}.
\end{equation}

\begin{exercise}\label{ex:triangle-0908}
    Compute $p_t = \left(p_t^1, p_t^2, p_t^3\right)$ for all $t \geq 0$ for the random walk on the

The solution is \cref{lem:triangle-0908}.

\begin{lemma}[Random Walk on the Triangle]\label{lem:triangle-0908}
    For the random walk on the triangle that starts at node $1$, for all $t \geq 0$,
    \[p_t^1 = \frac{1}{3} + \frac{2}{3} \left(-\frac{1}{2}\right)^{t},
        \qquad
        p_t^2 = p_t^3 = \frac{1}{3} - \frac{1}{3} \left(-\frac{1}{2}\right)^{t}.\]
    In particular, $p_t$ converges to $\left(\frac{1}{3}, \frac{1}{3}, \frac{1}{3}\right)$ as $t \to \infty$.
\end{lemma}

\begin{proof}
    Let $i$ be any of the three nodes, and let $j$ and $l$ be the other two. Both are neighbours of
    $i$ and have degree $2$, so by \cref{eq:walkstep-0908}, and since $p_t^i + p_t^j + p_t^l = 1$,
    \[p_{t+1}^i = \frac{p_t^j + p_t^l}{2} = \frac{1 - p_t^i}{2},
        \qquad\text{and hence}\qquad
        p_{t+1}^i - \frac{1}{3} = \frac{1 - p_t^i}{2} - \frac{1}{3}
        = -\frac{1}{2} \left(p_t^i - \frac{1}{3}\right).\]
    So the difference $p_t^i - \sfrac{1}{3}$ is multiplied by $-\sfrac{1}{2}$ in every step, and
    by induction on $t$
    \[p_t^i = \frac{1}{3} + \left(p_0^i - \frac{1}{3}\right) \left(-\frac{1}{2}\right)^{t}.\]
    With $p_0^1 = 1$ and $p_0^2 = p_0^3 = 0$ this gives the two formulas. Since
    $\left(-\frac{1}{2}\right)^{t} \to 0$, every entry converges to $\sfrac{1}{3}$.
\end{proof}

For $t = 0, 1, 2$ the formulas give $(1, 0, 0)$, $\left(0, \frac{1}{2}, \frac{1}{2}\right)$ and
$\left(\frac{1}{2}, \frac{1}{4}, \frac{1}{4}\right)$, in agreement with the example.
The next lecture writes \cref{eq:walkstep-0908} as a multiplication by a matrix, shows in
general that $p_t$ stays a probability vector (\cref{thm:probvec-0910}), and finds the distribution
that the walk does not change: it is proportional to the degrees (\cref{thm:stationary-0910}), which
for the triangle is the uniform distribution found here.

\section{The Law of Large Numbers}

% Notes p.9: "Show 'law of large numbers' with Chebyshev inequality."
\begin{exercise}\label{ex:wlln-0908}
    Show the ``law of large numbers'' with Chebyshev's inequality.
\end{exercise}

The law of large numbers says that the average of many independent samples of a random variable is
close to its expectation. The version that follows from Chebyshev's inequality is the \emph{weak} law,
\cref{thm:wlln-0908}.

\begin{theorem}[Weak Law of Large Numbers]\label{thm:wlln-0908}
    Let $X_1, X_2, \dots$ be pairwise independent random variables with the same expectation
    $\expectation{X_i} = \mu$ and the same finite variance $\variance{X_i} = \sigma^2$ (for example,
    independent and identically distributed with finite variance), and let
    $\overline{X}_n = \frac{1}{n} \sum_{i=1}^{n} X_i$. Then, for every $\eps > 0$,
    \[\prob{\abs{\overline{X}_n - \mu} \geq \eps} \leq \frac{\sigma^2}{n \eps^2}
        \longrightarrow 0 \qquad \text{as } n \to \infty.\]
\end{theorem}

\begin{proof}
    By linearity of expectation,
    \[\expectation{\overline{X}_n} = \frac{1}{n} \sum_{i=1}^{n} \expectation{X_i} = \frac{n \mu}{n} = \mu.\]
    For the variance, write $Y_i = X_i - \mu$, so that $\expectation{Y_i} = 0$,
    $\expectation{Y_i^2} = \sigma^2$, and $\overline{X}_n - \mu = \frac{1}{n} \sum_{i=1}^{n} Y_i$.
    Expanding the square as in the proof of \cref{lem:pairwise-0903},
    \[\variance{\overline{X}_n}
        = \expectation{\Big(\frac{1}{n} \sum_{i=1}^{n} Y_i\Big)^2}
        = \frac{1}{n^2} \sum_{i=1}^{n} \expectation{Y_i^2}
        + \frac{1}{n^2} \sum_{i \neq j} \expectation{Y_i Y_j}.\]
    For $i \neq j$, the variables $Y_i$ and $Y_j$ are independent, so
    $\expectation{Y_i Y_j} = \expectation{Y_i} \expectation{Y_j} = 0$, and the second sum vanishes. Hence
    \[\variance{\overline{X}_n} = \frac{1}{n^2} \cdot n \sigma^2 = \frac{\sigma^2}{n}.\]
    Chebyshev's inequality (\cref{thm:chebyshev}), applied to the random variable $\overline{X}_n$
    with $a = \eps$, now gives
    \[\prob{\abs{\overline{X}_n - \mu} \geq \eps}
        = \prob{\abs{\overline{X}_n - \expectation{\overline{X}_n}} \geq \eps}
        \leq \frac{\variance{\overline{X}_n}}{\eps^2} = \frac{\sigma^2}{n \eps^2},\]
    which tends to $0$ as $n \to \infty$ for every fixed $\eps > 0$.
\end{proof}

The statement that $\prob{\abs{\overline{X}_n - \mu} \geq \eps} \to 0$ for every $\eps > 0$ is called
\emph{convergence in probability} of $\overline{X}_n$ to $\mu$, and this is what ``weak'' refers to.
